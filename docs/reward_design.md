# 奖励函数设计文档

## 设计目标

在 UR5 机械臂抓取任务中，奖励函数的目标是：
1. 引导策略快速靠近目标物体
2. 鼓励成功抓取
3. 惩罚无效动作和超时

---

## 奖励公式

### 1. 成功抓取（距离 < 0.01m）

当机械臂末端与目标物体的欧几里得距离小于 1cm 时，判定为抓取成功：

reward = 100 + (max_steps - current_step)

- 基础奖励 100：明确告诉策略"抓取成功是最高优先级"
- 剩余步数奖励 (max_steps - current_step)：鼓励策略用最短时间完成抓取，防止拖延

设计意图：不仅奖励"成功"，还奖励"快速成功"。这能有效避免策略在目标附近徘徊而不执行抓取。

---

### 2. 失败或进行中（距离 >= 0.01m）

reward = -10 * distance

- 距离惩罚：惩罚与目标物体的距离成正比
- 系数 -10：经过调参确定，使惩罚幅度与成功奖励保持合理比例

设计意图：提供密集的梯度信号。即使没有成功抓取，策略也能从"距离缩短"中获得正向反馈（惩罚减小），从而学会逐步靠近目标。

---

## 为什么选择密集奖励而非稀疏奖励？

稀疏奖励（仅成功时 +1）：
- 优点：简单，易于实现
- 缺点：探索困难，收敛极慢

密集奖励（本设计）：
- 优点：提供持续梯度，收敛快
- 缺点：需要精心设计，可能引入局部最优

本项目的选择：采用密集奖励，因为机械臂的连续动作空间（2维平移）需要明确的梯度才能高效学习。

---

## 超参数调优记录

- 成功阈值：0.01m（约 1cm，物理意义上可判定为"抓取到"）
- 成功基础奖励：100（远大于单步惩罚，确保策略优先追求成功）
- 距离惩罚系数：10（经过实验，此系数能提供平滑的梯度信号）
- 最大步数：100（单回合上限，防止无限循环）

---

## 训练过程中的奖励变化观察

- 训练初期（0~2000步）：奖励多为负值，机械臂随机探索
- 训练中期（2000~8000步）：逐渐出现正奖励，偶尔成功抓取
- 训练后期（8000~14000步）：奖励稳定在 198~199，几乎每次都能快速抓取

最终收敛点：约 14,000 步时，100 次测试成功率达 100%。

---

## 参考代码实现（ur5_env.py 中的奖励计算逻辑）

distance_to_target = abs(np.linalg.norm(eef_position - self.target_pos))

if distance_to_target <= 0.01:
    steps_taken = self.max_steps - self.current_step
    reward = 100 + steps_taken
    done = True
elif self.current_step >= self.max_steps:
    reward = -10 * distance_to_target
    done = True
else:
    reward = -10 * distance_to_target
    done = False

---

## 总结

本奖励函数通过密集的距离惩罚和快速成功的奖励加成，成功引导 UR5 机械臂在 14,000 步内收敛到 100% 的成功率。该设计证明了在连续控制任务中，良好的奖励塑造可以显著提升训练效率。
